One sentence, in words a person from 1800 already knows, that explains the modern internet: a post office in a box in every home, a letter read in China before the tea cools with its answer returning as swiftly, and more books than any library on Earth.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

Writes the sentence to `entry.txt` in the output directory.
